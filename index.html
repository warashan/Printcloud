    Principio de reutilización

    Código listo para adaptar a plantillas HTML o componentes frontend.

    Los ejemplos de esta biblioteca usan las mismas clases de componente, tokens semánticos y reglas de interacción. Tailwind CSS v4 construye las utilidades; los componentes de dominio conservan clases semánticas como .btn, .field, .badge, .data-table y .dialog.
