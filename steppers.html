Página de steppers

Patrones de progresión para solicitudes, fotografía, revisión y emisión de tarjetas.

Flujo · Reposición In Situ

Stepper interactivo de cinco etapas, sin conexión a periféricos.

Etapa 1 de 5
1Identificación
2Fotografía
3Validación
4Revisión
5Impresión
Paso 01 / 05

Identificación del estudiante

Verifica RUT, nombres y tipo de solicitud antes de continuar.

Reglas de progresión
  • Mostrar paso actual y completados.
  • Permitir volver a pasos anteriores.
  • Bloquear acciones irreversibles sin confirmación.
  • No iniciar impresión desde esta maqueta.
Stepper vertical · referencia

Útil cuando se requiere describir cada etapa.

Cuándo utilizarlo

Usar stepper para procedimientos secuenciales con dependencia entre pasos. No utilizarlo como navegación libre entre páginas independientes. El estado debe permanecer sincronizado con el proceso real, no depender exclusivamente de clases CSS.

Prototipo funcional de interfaz · Datos de ejemplo · No reemplaza procesos productivos TNE.
