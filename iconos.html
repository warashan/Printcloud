Secciones de menú, accesos y estados destacados.

Uso recomendado

No usar símbolos distintos para una misma acción.

Estilo Lucide de trazo uniforme (2 px), sin mezclar outline y filled indiscriminadamente. Si el ícono es decorativo, ocultarlo a tecnologías asistivas; si es el único contenido de un botón, agregar una etiqueta accesible. Este prototipo incluye una selección de SVG en línea para funcionar sin conexión y como referencia para incorporar la biblioteca Lucide al proyecto definitivo.

<button aria-label="Ver detalle"> <!-- SVG Lucide: eye --> </button>
